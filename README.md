# Agricultural Data Analysis – Smart Crop Selection

A machine learning project for agricultural data analysis and smart crop recommendation using Python and Scikit-learn.

## Project Overview

This project analyzes agricultural soil, weather, environmental, and crop-related data to identify patterns affecting crop suitability and develop a machine-learning based crop recommendation system.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Project Workflow

1. Data Cleaning and Preprocessing
2. Exploratory Data Analysis
3. Feature Analysis and Visualization
4. Handling Class Imbalance using SMOTE
5. Feature Scaling
6. Train-Test Split
7. Random Forest Classification
8. Hyperparameter Optimization using GridSearchCV
9. Smart Crop Recommendation

## Smart Crop Recommendation System

The system accepts:

- Soil Type
- Season
- Irrigation Type
- Temperature
- Rainfall
- Humidity

Based on these inputs, the machine learning model predicts a suitable crop and provides a visualization of the relative suitability of multiple crops.

## Project File

- `Smart_Crop_Selection_Project.ipynb` – Complete project notebook containing data analysis, preprocessing, machine learning, evaluation, and crop recommendation.
